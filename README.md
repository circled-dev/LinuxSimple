# Linux-Simplified-distro
a **Linux distro based off of Debian** **Not endorsed by Debian or created by Debian. Created by circledx1.**

This distro is based of **Debian 13**, Also known as **Debian Trixie** This DISTRO IS NOT OWNED NOR ENDORSED BY DEBIAN.

This is just a hobby type project, and this project is done thanks to Live-Build (What Debian uses for their Distro building)

NOTE: **If you use a VM on this Distro** you will encounter a 'Kernel Mismatch' and I have not found a way to fix it, but if you could use a machine to boot it up, that should work.


Requirements
Architecture: **AMD64 ONLY**
Hardware: **Check official Debian requirements as this operating system is based of Debian** and also **Intel & AMD is supported out of the box** **If you do not have hardware that is well supported on Linux, please check your hardware at https://linux-hardware.org/ I am not the creator of that website or affiliated with the creator of that website at ALL.**
