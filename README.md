# Linux-Simplified-distro
a **Linux distro based off of Debian** **Not endorsed by Debian or created by Debian. Created by circledx1.**
**This distro is based of Debian 13 aka Trixie, and this distro will get updated, but once it stops getting updates,it will get archived.**
This distro currently supports AMD64 only, and supports AMD drivers, Intel drivers, Nvidia drivers (Nvidia Open Source Driver)
Installation
1. Git clone the repo (git clone https://github.com/circled-dev/LS-OS
2. Download live-build according to your distro | If you use Debian based sudo apt install live-build, if you use Arch based distros, do sudo pacman -S live-build, live-build is the way to build the ISO so you can boot it up.
3. type in 'sudo lb config' then 'sudo lb bootstrap' and then 'sudo lb build' and you must wait until it finishs and returns back to prompt.
4. Check the folder **From the REPO** and you should see the hybrid .ISO (cx-os) and you are good to go.
